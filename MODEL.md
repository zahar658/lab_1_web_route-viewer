# Алгоритм расчёта

1. Из CSV берём расстояния и выбранный профиль высот. Длинные отрезки делим; высоту между исходными точками определяем линейно.
2. По уклонам определяем подъёмы. Перед подъёмом оцениваем запас скорости по набору высоты, крейсерской скорости и коэффициенту запаса разгона.
3. Через каждый шаг времени определяем необходимую мощность. На подъёме мощность может только снижаться; на пологом спуске тяга разрешена, если наката недостаточно.
4. Рассчитываем качение, сопротивление воздуха и действие уклона. По сумме сил определяем ускорение. Проверяем сцепление, передачи, доступную мощность, скорость и торможение. Финишная скорость имеет приоритет при подходе к финишу.
5. Расход в л/ч получаем из мощности и приближённого BSFC, зависящего от оборотов и нагрузки. Топливо за шаг считаем методом трапеций. Отсечка на спуске моделируется нулевым расходом.
6. Повторяем весь маршрут для разных крейсерских скоростей, дистанций разгона, коэффициентов запаса скорости и долей мощности на вершине. Сохраняем вариант с меньшим общим расходом среди выполнивших ограничения.
7. Если ни один вариант не подходит, группируем ошибки и показываем примеры с расстоянием и нарушенным ограничением.

Средняя скорость задаёт предельное время, а не скорость в каждой точке. Поиск ограничен набором вариантов: глобальный минимум не гарантируется. Параметры управления общие для всего маршрута, но целевая скорость перед подъёмом зависит от его высоты. Коробка переключается мгновенно; нагрев тормозов, ветер, остановки и ограничения на поворотах не моделируются.

Высоты сглаживаются средним по расстоянию в окне. Между точками используется линейный профиль; площадь под ним делится на длину окна. Исходные высоты сохраняются отдельно.

## Восстановление по координатам

recovery.py проходит по наблюдаемым координатам файла 2. Для каждой соседней пары использует формулу гаверсинуса и сравнивает расстояние с порогом. Разрывы нумерации и значения distance_from_start_m не участвуют. Каждая обнаруженная пара становится отдельным запросом driving-car с высотами. Затем точки ответа вставляются между сохранёнными наблюдениями; расстояния и производные показатели пересчитываются. Никакого обучения и доступа к файлу 1 нет. Восстановление не выполняет поиск оптимального совпадения с исходным маршрутом: оно принимает путь, который предложил API.
