## Прогресс расчёта

Во время расчёта под кнопкой отображаются приблизительный процент, полоска прогресса и прошедшее время. Оценка основана на длительности ожидания, размере маршрута и настройках точности, а не на фактическом числе выполненных операций. Она может замедляться и не предсказывает точное время завершения. До ответа сервера показывается не больше 99%; 100% означает, что сервер вернул результат, в том числе результат без допустимого решения. При ошибке связи индикатор скрывается и показывается сообщение об ошибке.

# Обновление подбора скорости

Максимальная скорость по умолчанию — 120 км/ч. Она является ограничением, а не целью движения. При необходимости измените её под условия поездки.

Перед каждым подъёмом целевая скорость определяется его набором высоты, выбранной крейсерской скоростью и подбираемым коэффициентом запаса разгона. Короткие невысокие подъёмы больше не требуют обязательного разгона до максимальной скорости. Входная мощность также согласуется с выбранным темпом. Скорость, тяга и проходимость проверяются полной симуляцией.

Поиск проверяет крейсерские скорости ниже заданной средней, уточняет более медленные варианты и совместно меняет скорость и остаточную мощность на вершине. Из допустимых вариантов выбирается минимум литров. При этом не требуется искусственно растягивать поездку ровно до лимита: выводится фактический запас времени. Формула предварительного разгона эвристическая; глобальный минимум и отдельная независимая оптимизация каждого подъёма не гарантируются.

«Экономичный поиск» проверен на полном маршруте 697,12 км. Лимит размера сетки увеличен до 12 млн пар скоростей для диапазона до 120 км/ч. Точность и ограничения двигателя сохранены. Большие маршруты могут требовать несколько минут расчёта.

Для обновления остановите сервер, распакуйте архив в новую папку, запустите START.bat и обновите обе страницы Ctrl+F5. Проверьте значение максимальной скорости в параметрах и пересчитайте маршрут.

# Обновление: пологие спуски и понятные ошибки

На спуске модель сравнивает сопротивления с действием тяжести и требуемым ускорением. Если накат обеспечивает выбранное движение, подача топлива отключается. Иначе разрешается тяга для поддержания выбранной скорости. Предварительный разгон разрешён и на спуске. Крейсерская скорость по-прежнему подбирается по общему расходу и ограничению времени; глобальный минимум не гарантируется.

Ручной метод удалён из интерфейса и API. Введённые параметры остаются исходным вариантом для автоматического поиска. Ошибки объединяются по причинам: показываются число отклонённых вариантов, пример с расстоянием и конкретным ограничением. Для недостаточной скорости выводятся скорость, минимум, уклон и мощность.

На границах доступной мощности передачи расчёт уменьшает команду мощности и при необходимости уточняет временной шаг, вместо немедленного отказа. Если подходящей передачи нет, возвращается ошибка. Финишная скорость теперь учитывается и при финише на подъёме; приближение к финишу может потребовать дополнительного снижения мощности и торможения.

## Новый режим экономии

Выберите «Экономия: разгон → подъём → накат», загрузите CSV, задайте массы и параметры грузовика, нажмите «Рассчитать скорость». Подбор может занять несколько минут на длинном маршруте. Не закрывайте вкладку до результата.

Сохраняется логика: максимальный доступный разгон перед подъёмом до ограничения скорости, невозрастающая мощность на каждом обнаруженном подъёме, накат на спуске, когда его достаточно, и тяга на пологом спуске при необходимости. Алгоритм подбирает крейсерскую скорость, дистанцию предварительного разгона и процент мощности у вершины по суммарным литрам. Проверяются исходные настройки и ограниченный набор вариантов методом последовательного поиска по параметрам. Это минимум среди проверенных вариантов, не доказанный глобальный минимум.

Заданная средняя скорость означает нижний предел средней скорости по всему маршруту (эквивалент верхнего предела времени). Начальная, конечная, минимальная и максимальная скорости остаются ограничениями. Параметры двигателя, массы и физические ограничения при поиске не изменяются. Выбранные настройки отображаются в результатах и сохраняются в CSV расчёта. Если исходный вариант допустим, результат поиска не расходует больше топлива, чем он.

«Экономичный поиск» — прежний поиск по сетке скоростей; он не обязан соблюдать невозрастание мощности на подъёме.

Исправление ошибки ускорения: на спуске ограничение ускорения теперь применяется вместе с ограничением скорости. Избыточную силу компенсируют тормоза с проверкой их возможностей. Раньше ускорение от тяжести могло превышать лимит, после чего проверка останавливала расчёт.

Проверки: python tests/test_eco.py, python tests/test_terrain_strategy.py, python tests/test_truck_model.py. Физика и карта расхода учебные, реальные данные конкретного двигателя требуют калибровки.

# Профиль маршрута

Локальное веб-приложение для Windows 11. Карта занимает 80% нижней области, панель параметров транспорта — 20%. Сверху — график с переключением показателя и горизонтальной оси.

## Запуск на Windows 11

1. Распакуйте весь ZIP в отдельную папку, например `C:\RouteViewer`. Не запускайте файлы внутри архива.
2. Установите Python 3.10 или новее с https://www.python.org/downloads/windows/ (если уже установлен, пропустите). При установке отметьте Add python.exe to PATH.
3. Дважды нажмите START.bat. Откроется браузер. Если он не открылся, скопируйте адрес http://127.0.0.1:… из окна запуска.
4. Оставьте окно запуска открытым. Нажмите «Открыть маршрут» и выберите CSV (например, приложенный route.csv).
5. Для остановки нажмите Ctrl+C в окне запуска и закройте его.

Ручной запуск из терминала в папке приложения: `py -3 start.py`.
Node.js и npm не нужны. Для просмотра готовых CSV API-ключ не нужен; для генерации нового маршрута необходим ключ openrouteservice. Сервер слушает только 127.0.0.1 и выбирает свободный порт. Запускайте приложение через START.bat, чтобы карта работала через локальный HTTP-сервер.

## Работа

- Перемещение карты — перетаскивание; масштаб — колесо мыши или кнопки +/−.
- «Весь маршрут» возвращает масштаб по границам маршрута.
- Новый CSV заменяет текущий маршрут. Ошибочный CSV сохраняет предыдущий маршрут.
- Наведение на график выделяет точку на карте, показывает номер, расстояние и значение. График также поддерживает выбор точки стрелками клавиатуры после фокусировки.
- Горизонтальная ось: порядковая позиция точки (от 0) или расстояние, км. Подсказка использует исходный point_id, если он присутствует.
- Пустые значения не заменяются нулями; график содержит разрывы. Без высоты и уклона доступна только карта.
- Файл route.csv — приложенный маршрут Владивосток — Хабаровск, 15 182 точки, 759,045 км.

## CSV

UTF-8, включая BOM. Разделитель: запятая, точка с запятой или табуляция. Поддерживаются кавычки и десятичная запятая при разделителе «;». Обязательные столбцы: latitude и longitude (также lat, lon/lng, широта, долгота). Порядок строк определяет маршрут. Минимум две точки, максимум 30 МБ. Некорректные координаты или количество полей вызывают ошибку с номером строки.

Поддерживаются point_id, elevation_m, elevation_smoothed_m, distance_from_start_m, elevation_delta_m, slope_pct, slope_deg, slope_smoothed_pct. Высота: метры, координаты: десятичные градусы WGS84. Для elevation_m также допустимы elevation, altitude, height, высота.

Значения из файла имеют приоритет. При отсутствии уклона он вычисляется по разности исходных высот и расстоянию между координатами (формула гаверсинуса): уклон % = 100 × Δh / расстояние; угол = atan(уклон % / 100). При наличии только одной формы уклона вторая вычисляется из неё. У первой точки вычисляемый уклон отсутствует. При совпадающих координатах вычисляемый уклон отсутствует.

Расстояние берётся из distance_from_start_m, если весь столбец заполнен неотрицательными неубывающими значениями; иначе вычисляется по координатам. Начальное значение вычитается. Накопленный подъём — сумма положительных разностей исходных высот. При пропусках высоты он недоступен, чтобы не создавать неверный итог. Шум высот может завышать подъём и уклон; сглаженные показатели доступны в режиме «Сглаженные», если присутствуют в CSV.

## Диапазон графика по карте

График автоматически обновляется после перемещения и масштабирования карты. Его границы — первая и последняя точки маршрута, попадающие в видимую область. Номера точек и километры сохраняют отсчёт от начала всего маршрута. Масштаб вертикальной оси также подстраивается под этот участок.

Если в область попали несколько раздельных частей маршрута, показывается непрерывный диапазон между первой и последней видимыми точками, включая промежуточные точки за пределами экрана. Если видна одна точка, она отображается отдельно. Если ни одна точка не попадает на карту, график сообщает об этом. Отрезок между редкими точками сам по себе не считается видимой точкой. «Весь маршрут» возвращает полный диапазон.

В списке показателей оставлены уклон в градусах, уклон в процентах, высота и перепад высоты. Для высоты, перепада и уклона можно выбрать исходный или сглаженный профиль. Накопленный подъём не выводится.

## Движение транспорта

После загрузки CSV оранжевая точка ТС появляется в начале маршрута. «Запуск» начинает движение, «Пауза» сохраняет положение. «В начало» и «В конец» останавливают движение и переводят точку к соответствующему концу маршрута; карта центрируется на ней с сохранением масштаба. После финиша повторный запуск начинает маршрут заново. Новый CSV сбрасывает движение. Ошибочный CSV не заменяет маршрут.

Параметры справа: скорость 0–300 км/ч, масса ТС 1–1 000 000 кг и масса груза 0–1 000 000 кг. Отображается общая масса. Массы используются в модели дизельного грузовика при расчёте скорости и топлива. Значения действуют в текущем сеансе страницы и сбрасываются при обновлении.

Множитель анимации ×1 / ×10 / ×100 / ×1000 ускоряет модельное время; по умолчанию ×100. При ×1 скорость 60 км/ч соответствует 16,67 метра маршрута за секунду. Позиция плавно интерполируется между точками по расстоянию. При нулевой скорости ТС стоит; изменение скорости действует без перезапуска. При переключении на другую вкладку движение ставится на паузу, чтобы не пропускать участок.

«Следить за ТС» центрирует карту на движущейся точке. Если режим выключен, карту можно изучать независимо. График по-прежнему показывает диапазон видимой карты. Бирюзовая точка наведения на график и оранжевая точка ТС независимы. Прогресс и пройденное расстояние отображаются сверху, рядом со скоростью анимации и переключателем слежения. На узких мобильных экранах панель параметров располагается под картой.

## Положение ТС на графике

Оранжевая точка и вертикальная пунктирная линия показывают текущее положение ТС на выбранном графике. Положение между точками маршрута и значение показателя интерполируются линейно. Работают обе горизонтальные оси: номер точки и километры. При отсутствии значения показателя отображается только вертикальная линия. Если ТС вне диапазона графика, отметка скрыта; включите «Следить за ТС», чтобы карта и диапазон графика следовали за ним. Отметка наведения мыши остаётся независимой.

Скорость анимации, «Следить за ТС», статус движения, прогресс и пройденное расстояние перенесены в верхнюю панель. Справа оставлены физическая скорость и параметры массы.

## Генерация нового маршрута

1. Полностью остановите старый сервер, замените файлы и запустите новый START.bat. Откройте показанный адрес в Microsoft Edge или Google Chrome и обновите страницу Ctrl+F5.
2. Нажмите «Создать маршрут» в верхней панели. Движение ТС будет поставлено на паузу.
3. Введите свой API-ключ openrouteservice. Ключ маскируется, не записывается в файлы, localStorage или журнал сервера и очищается при закрытии окна.
4. Введите начальную и конечную точки: населённый пункт/адрес или координаты. Координаты в форме: широта, долгота, например `43.1155, 131.8855`. Дробная часть — через точку. В скрипте командной строки порядок остаётся исходным: долгота широта.
5. Нажмите «Проверить» для каждой точки. Названия проверяются поиском openrouteservice; если найдено несколько мест, явно выберите нужное. Для координат проверяются формат и допустимые диапазоны. Возможность проезда по дорогам проверяется сервисом при построении маршрута. Точки должны отличаться минимум на 1 метр.
6. Нажмите «Сгенерировать CSV». Запрос может занять до трёх минут. Ошибки ключа, лимита, сети или маршрута появятся в окне. При изменении точек их необходимо проверить заново.
7. Нажмите «Сохранить CSV как…». В системном диалоге выберите папку и имя файла. Для этого используется showSaveFilePicker в Edge/Chrome на локальном адресе 127.0.0.1. Если браузер не поддерживает выбор пути, приложение попросит открыть его в поддерживаемом браузере — файл не сохраняется автоматически в случайную папку.
8. При отмене сохранения готовый CSV остаётся доступен до изменения формы или обновления страницы. Нажмите сохранение снова. Затем откройте сохранённый файл кнопкой «Открыть маршрут».

Приложение использует расширенный build_rows: одна строка CSV на одну исходную точку API. Исходные столбцы не изменяются; сглаженные значения записываются отдельно. Координаты и высоты ответа читаются через Decimal для сохранения исходных числовых значений. Генерация из интерфейса сохраняет только выбранный CSV, без вспомогательных JSON-файлов. Исходный CLI в route_to_csv.py также доступен; новая поставляемая копия поддерживает чтение ключа из ORS_API_KEY или скрытого ввода. Приложенный исходный файл пользователя не изменялся.

Названия мест передаются в геокодер openrouteservice (https://giscience.github.io/openrouteservice/api-reference/endpoints/geocoder/). Построение дорог использует directions/driving-car с elevation=true. API может привязать точки к ближайшей доступной дороге; совпадение с введённой координатой не гарантируется. Требуется действующий ключ с доступом к соответствующим сервисам и доступный лимит запросов.

Проверены локальная валидация, обработка ошибок API и HTTP-интеграция с подставленными ответами. Реальный запрос с пользовательским API-ключом и диалог сохранения в браузере в среде разработки не проверены.

## Исправление HTTP 406

Для запроса directions/driving-car/geojson используется Accept: application/geo+json, как в исходном скрипте. Для геокодирования оставлен application/json. При обновлении обязательно остановите старый сервер и заново запустите START.bat: обновления страницы недостаточно для перезагрузки Python-кода.

## Исходные точки API

Новая генерация использует расширенную версию route_to_csv(2).py (в архиве — route_to_csv.py). latitude, longitude и elevation_m передаются в CSV напрямую, с сохранением исходных числовых значений. Строк столько же, сколько точек в геометрии API; порядок и повторяющиеся координаты сохранены. Сглаженные данные записываются в дополнительные столбцы.

Расстояния, перепады высоты, уклон и направление по-прежнему вычисляются скриптом; они не являются исходными полями API. На нулевых отрезках уклон и направление остаются пустыми. Короткие отрезки могут давать резкие скачки уклона, расстояния между точками неравномерны. Для изучения профиля полезна горизонтальная ось «Расстояние, км».

Плавное движение ТС и положение оранжевой точки на графике интерполируются только при отображении и не меняют сохранённый CSV. Старые CSV остаются совместимыми. В браузере числа представлены обычными JavaScript Number; точность отображения может отличаться от десятичных значений сохранённого CSV. Через интерфейс сохраняется только CSV; отдельный запуск скрипта создаёт также исходный JSON и метаданные.

## Исходный и сглаженный профиль в одном CSV

При генерации задайте «Окно сглаживания, м» (по умолчанию 250, в интерфейсе 1–10 000 м). После открытия нового CSV переключайте «Данные → Исходные / Сглаженные» над графиком. Переключатель применяется к высоте, перепаду, уклону в градусах и процентах, подсказкам и оранжевой точке ТС. Координаты маршрута остаются прежними.

Исходные столбцы elevation_m, elevation_delta_m, slope_pct, slope_deg сохраняются. Дополнительные столбцы:
- elevation_smoothed_m — сглаженная высота;
- elevation_delta_smoothed_m — разность сглаженных высот соседних точек;
- slope_smoothed_pct и slope_smoothed_deg — уклоны по сглаженным высотам и исходной длине отрезка;
- smoothing_window_m — полная ширина окна в метрах.

Метод — среднее по расстоянию в скользящем окне: интеграл кусочно-линейного профиля высот, делённый на ширину доступного окна. Для 250 м учитывается по 125 м до и после точки. У границ маршрута окно обрезается. Поэтому плотные группы точек не получают больший вес только из-за своего количества. Повторяющиеся расстояния усредняются только во вспомогательной модели сглаживания; исходные строки и высоты не удаляются и не изменяются. На нулевых отрезках уклон остаётся пустым.

Большее окно сильнее подавляет короткие колебания, но также размывает реальные подъёмы и спуски. Сглаживание не исправляет систематические ошибки API и не гарантирует правильность высот дороги. Исходные данные всегда доступны для сравнения. Плавная анимация по карте не изменяет данные CSV.

Старые CSV без сглаженных столбцов открываются в исходном режиме; для второго режима создайте маршрут заново. Старые CSV со сглаженной высотой поддерживаются; недостающие сглаженные уклоны вычисляются при чтении. Если сохранился route_raw.json, оба профиля можно получить без запроса к API: `py -3 route_to_csv.py --from-json route_raw.json --smooth-window 250 --out output`.

Проверены сохранность исходных десятичных значений, дубликаты, уменьшение тестового пика, независимость среднего от плотности точек, расчёт уклона, переключение профилей и отметка ТС. Реальный запрос API и визуальная проверка в браузере в этой среде не выполнялись.

## Расчёт экономичной скорости дизельного грузовика

Справа добавлены «Параметры грузовика», выбор исходного/сглаженного рельефа и «Рассчитать скорость». Ограничение — минимальная средняя скорость, то есть максимальное время поездки. Результат: допустимый профиль скорости, топливо, время и средняя скорость. После расчёта доступны новые графики, воспроизведение по рассчитанной скорости и экспорт результата CSV.

Параметры двигателя, трансмиссии, расхода и сопротивлений редактируются. Начальные массы теперь 12 000 кг ТС + 10 000 кг груза. Модель учебная, карта расхода синтетическая; поиск приближённый и не гарантирует глобального минимума. При отсутствии допустимого решения приложение сообщает об этом.

Подробные формулы, допущения, ограничения сетки и инструкция — MODEL.md. Для обновления обязательно остановите старый сервер и запустите новый START.bat. Расчёт выполняется локально, без API-ключа и дополнительных пакетов Python.

## График скорости, перемещение ТС и страница анализа

Расчётная скорость доступна в списке «По вертикали». Отдельная кнопка «График скорости» удалена. Сначала выполните расчёт справа. После успешного расчёта режим «Движение по расчёту» включается автоматически: ТС следует найденному профилю, включая разгон и замедление. Поле ручной скорости удалено. Ручного режима и переключателя больше нет. Множитель анимации влияет только на воспроизведение.

Во время паузы можно переместить ТС тремя способами: ползунком «Положение ТС» в верхней части, щелчком по графику или перетаскиванием оранжевой точки на карте мышью. На карте точка привязывается к ближайшему отрезку маршрута; на пересечениях возможен выбор другого близкого участка, поэтому для точного выбора используйте график или ползунок. На сенсорном экране используйте ползунок или щелчок по графику. Во время движения перемещение заблокировано. «Запуск» продолжает движение с выбранного места; накопленный расход соответствует позиции в рассчитанной поездке, а не сумме произвольных перемещений пользователя.

«Все графики» открывает отдельную вкладку analysis.html. Основное окно оставьте открытым: оно передаёт текущий маршрут и расчёт напрямую, без отправки на сервер или записи API-ключа. На странице друг под другом расположены высота, уклон в градусах, уклон в процентах, перепад высоты, скорость, расход л/ч, накопленное топливо, мощность и передача. Исходный и сглаженный рельеф показаны вместе разными цветами. Мощность содержит требуемую и доступную линии.

У всех графиков общая ось расстояния. Поля «От / До» задают диапазон в километрах; колесо мыши масштабирует все графики около указателя. «Весь маршрут» сбрасывает диапазон. Курсор и линия положения ТС синхронизированы. Щелчок по любому графику перемещает ТС в основном окне, если движение на паузе. Обновление расчёта в основном окне обновляет страницу анализа. Без расчёта показаны рельеф и пояснения вместо графиков модели. Если основное окно закрыть, уже открытая страница сохраняет последний полученный снимок только в памяти; после обновления без основного окна данные недоступны.

Расход, мощность и передача на странице анализа показываются ступенями по расчётным участкам; это усреднённые показатели участка, как описано в MODEL.md. Скорость и накопленное топливо вычисляются по модели движения между узлами; линии на графике соединяют узлы, подсказки используют расчётное значение в выбранной позиции.

Автоматически проверены управление позицией, запрет перемещения во время движения, границы маршрута, девять графиков, общий диапазон и отсутствие расчёта. Визуальная проверка в браузере не выполнялась.

## Настройка страницы графиков

На странице «Все графики» уменьшены высота графиков, внутренние отступы и промежутки. Раскройте «Выбрать графики» и отметьте нужные панели. Порядок меняется перетаскиванием заголовка мышью или кнопками ↑ / ↓ (подходят также для сенсорного экрана и клавиатуры). Скрытые панели не отрисовываются; включение возвращает их в текущую последовательность. Можно скрыть все панели, затем включить нужные. Выбор и порядок действуют до обновления страницы; при смене маршрута в основном окне сохраняются. Общий диапазон расстояний и указатели остаются синхронными.

Название «сглаженный уклон» означает уклон, рассчитанный по сглаженным высотам. Сам уклон вторым фильтром не сглаживается. Исходный slope_pct = 100 × (h_i − h_(i−1)) / ds. Сглаженный slope_smoothed_pct = 100 × (h_smooth_i − h_smooth_(i−1)) / ds. Угол в градусах равен atan(уклон / 100) × 180 / π. ds одинаковое в обоих вариантах; на нулевом отрезке уклон отсутствует. Изменяется исходный профиль высот для расчёта, а не формула.

## Только расчётное движение

Поле «Скорость» в разделе «Транспорт» и переключатель «Движение по расчёту» удалены. Теперь «Запуск» доступен только после успешного расчёта. Изменение параметров или маршрута аннулирует расчёт и блокирует запуск до нового расчёта. Пауза, перемещение по маршруту, переход в начало/конец и множитель воспроизведения сохраняются. Множитель изменяет темп просмотра, но не рассчитанные скорость, время и топливо.

График расхода показывает средние л/ч для каждого расчётного участка ступенями. Ступени — представление дискретной модели, а не предсказание мгновенных скачков подачи топлива реального дизеля. Переходы зависят от уклона, ускорения, выбранной передачи и приближённой карты расхода. Отдельного штрафа за рывки, изменения тяги и переключения передач пока нет.

## Стратегия разгона, подъёма и наката

В режиме «Разгон → подъём → накат» перед подъёмом используется максимальный доступный разгон в пределах ограничений. На входе фиксируется мощность, затем она снижается по расстоянию к вершине, без повторного повышения на этом подъёме. Настройка «Мощность у вершины, % от входной» по умолчанию равна 20%. Если физические ограничения снизили мощность раньше, она остаётся ниже заданной кривой.

Ограничение темпа мощности удалено. Команда меняется мгновенно, кроме предусмотренного постепенного снижения на подъёме. Реальная задержка двигателя не моделируется. Расход следует нагрузке и оборотам, а не сглаживается отдельно. Переключения передач могут вызывать скачки расхода.

Скорость на вершине определяется физикой, а не принудительным достижением минимума. Если не хватает скорости или мощности, расчёт сообщает об этом. Нулевая подача на спуске моделирует отсечку на включённой передаче с питанием вспомогательных нагрузок от колёс. Скорость ограничена сверху, но максимум не навязывается вопреки физике.

Это эвристика, а не гарантия минимального расхода. Прежний «Экономичный поиск» сохранён для сравнения. Подробные формулы, определение отдельных подъёмов и ограничения — в MODEL.md.

Для обновления остановите старый сервер, распакуйте новую версию в отдельную папку, запустите START.bat, обновите обе страницы Ctrl+F5 и выполните расчёт заново.
